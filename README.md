# rodpru/homebrew-tap

Homebrew tap for [Orchard](https://github.com/rodpru/orchard).

```bash
brew install --cask rodpru/tap/orchard
```

Orchard is not notarized by Apple. The cask removes the quarantine flag after install, so macOS opens the app without a Gatekeeper prompt. Install it only if you trust this tap.

The Orchard release workflow updates `Casks/orchard.rb` on each tagged release.
